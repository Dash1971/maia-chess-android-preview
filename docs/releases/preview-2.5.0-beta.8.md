# Preview 2.5.0-beta.8

Mobile Maia Preview **2.5.0-beta.8** (2508) combines reviewed PRs #188, #190, #191 and #192.

- Settings gains a Board card for coordinates, destination dots, last-move highlights, animation, dragged-piece magnification and drag target.
- Choose among 25 offline boards and 16 audited piece sets, with visual selectors and previews. Existing installs retain Brown/Cburnett and their previous aids.
- The board editor gains graphical palettes, tap/drag/place/erase tools, flip, position settings, validated analysis/play flows and FEN copy/share. Image import remains unavailable.
- Optional **Show Maia win (score) %**, off by default, displays each engine’s rating-conditioned expected game score in the existing analysis title area. It counts a draw as half a point and is not a literal win probability.

All ten languages are supported. Existing games and settings are preserved. Preview retains its package, 79M model and signing identity. Grand Kingdom/DGT remain Dev-only. Stable and Dev releases are unchanged.

Qualification: exact-source GitHub Linux build plus byte-identical independent Linux reproduction, established production certificate and signature reconstruction, full ARM64/79M native suite, signed beta.7 upgrade and changed-feature checks. Public-download verification and immediate task-owned cleanup are recorded with the release evidence. Physical Chessnut/phone acceptance remains with testers.

Exact-source evidence will be linked after qualification and publication.
