# Preview 2.6.0-beta.2

Completes the Home camera scan UI missing from beta.1 (#220).

- Scan board appears beside Analysis Board on Home, stacking for narrow screens and larger text.
- Opens the installed camera, reads a detected grid automatically, and opens the existing Board Editor for correction, position settings, analysis or Continue from here.
- If framing needs adjustment, drag the four corners or move the frame; Retake, Rotate image, Use photo, gallery selection and accessible Adjust edges controls remain available.
- Cancellation and late results preserve the prior session. No hidden analysis page, new acknowledgement screen, permission, dependency, runtime or recognition-model change.

Recognition remains editable assistance for flat screenshots/diagrams, with known accuracy limits; 3D-board recognition and broad real-phone/OEM acceptance remain pending. Grand Kingdom stays experimental with the known capture failures accepted for Preview testing; DGT remains Dev-only. Stable and Dev releases are unchanged.
