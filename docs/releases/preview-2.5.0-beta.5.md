# Preview 2.5.0-beta.5 (2505)

Preview 2.5.0-beta.5 improves analysis navigation through variations. Short taps step within the current line; Back crosses to its actual parent. At a variation’s end, Right is dimmed for tapping while either arrow can still be held to return to the main-line branch point. Further taps follow the main line. Main-line holds still jump to game endpoints, and accessibility describes the available hold action.
